Why it is different from cloud monitors

  • Login-protected pages work. The check uses your own signed-in session, so a members-only price or an internal dashboard is readable.
  • Bot protection rarely triggers. The request comes from your everyday browser, not a data-center IP that anti-bot systems are tuned to catch.
  • Your data stays put. Monitored values are stored locally. No account, no server, nothing uploaded. Privacy policy.
The honest trade-off — read this before buying Checks run while your browser is open. If your computer is off, checks pause. Pro runs the missed checks as soon as you come back and warns you if things fell too far behind, but this is not a 24/7 cloud monitor. If you need checks while your machine is asleep, a cloud service is the right tool and I would rather you buy that instead.

How the license works

After payment you receive a license key. Paste it into the extension's Pro page and the features unlock. The key is a token signed with an ECDSA P-256 private key; the extension verifies the signature with a bundled public key.

  • No account to create.
  • No license server — verification makes zero network requests and works offline.
  • Nothing about you is reported when you activate or use Pro.
